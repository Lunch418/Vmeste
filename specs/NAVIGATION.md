# NAVIGATION.md — «Вместе»

Навигация и переходы между экранами. См. также `specs/COMPONENTS.md`.

## 1. Общая карта экранов

```mermaid
flowchart TD
    Onboard[Онбординг / Регистрация] --> Feed[Лента событий]

    Feed -->|таб: Создать| Wizard[Создание события — wizard]
    Feed -->|таб: Профиль| Profile[Профиль]
    Feed -->|тап по карточке| Detail[Карточка события]

    Detail -->|Присоединиться| Deposit[Экран депозита]
    Deposit -->|эскроу подтверждён| Chat[Чат события]
    Detail -->|я постер / уже участник| Chat

    Chat -->|время встречи настало| Confirm[Подтверждение встречи]
    Confirm -->|AR-селфи 2 лица| Rating[Оценка после встречи]
    Confirm -->|QR fallback| Rating

    Rating --> Feed

    Wizard -->|5 шагов пройдены| Detail

    Profile --> Settings[Настройки]
    Profile --> History[История встреч]

    Detail -->|Пожаловаться / Заблокировать| Report[Жалоба]
```

## 2. Wizard создания события (5 шагов, сторис-стиль)

```mermaid
flowchart LR
    S1[1. Фото / афиша] --> S2[2. Тип активности]
    S2 --> S3[3. Дата, время, место]
    S3 --> S4[4. Места, возраст, пол]
    S4 --> S5[5. Описание, депозит]
    S5 --> Publish[Публикация в ленту]

    S2 -.назад.-> S1
    S3 -.назад.-> S2
    S4 -.назад.-> S3
    S5 -.назад.-> S4
```

Свайп вправо/влево или кнопки "Назад" — как переключение сторис. Прогресс сохраняется при выходе (draft), кроме случая явной отмены.

## 3. Поток подтверждения встречи

```mermaid
flowchart TD
    Start[Время встречи наступило] --> Choice{Способ подтверждения}
    Choice -->|Камера доступна| AR[AR-селфи: 2 лица в кадре]
    Choice -->|Камера недоступна / отказ| QR[QR: постер генерирует, джойнер сканирует]

    AR -->|распознаны оба лица| Filter[Случайный AR-фильтр применяется]
    Filter --> Send[Отправить]
    Send --> Confirmed[Встреча подтверждена]

    QR --> Confirmed

    Confirmed --> Escrow[Депозиты возвращаются по правилам]
    Escrow --> RatingScreen[Оценка друг друга]
```

## 4. Нижняя навигация (TabBar, мобильный)

```mermaid
flowchart LR
    Tab1[Лента] --- Tab2[Создать] --- Tab3[Профиль]
```

На десктопе (≥1024px) — та же тройка в виде боковой панели, без изменений в логике переходов.

## 5. Модальные и вложенные экраны

- `DepositSheet` — bottom sheet поверх `Detail`, не отдельный роут
- `Report` — модальное окно поверх `Detail` или `Profile`
- `SmsCodeInput` — отдельный шаг внутри `Onboard`, не самостоятельный экран в истории навигации (back возвращает к вводу телефона)

## 6. Правила навигации

- Back-жест/кнопка всегда возвращает на предыдущий экран истории, кроме: `Confirm → Rating` (нельзя вернуться в подтверждение после оценки)
- `Chat` доступен только участникам события с `status: joined | confirmed`
- Попытка открыть `Confirm` до наступления времени события — редирект на `Chat` с подсказкой
- После `Rating` — редирект на `Feed`, не на `Detail` (событие уже архивируется через 2 часа)
