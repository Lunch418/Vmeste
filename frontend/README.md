# Вместе — frontend

React + TypeScript + Vite PWA. См. `specs/COMPONENTS.md`, `specs/NAVIGATION.md`, `specs/CHANGES.md`.

## Запуск

```bash
npm install
npm run dev
```

По умолчанию API ожидается на `http://localhost:8000` (см. `backend/`). Переопределить — переменная окружения `VITE_API_BASE`.

## Сборка

```bash
npm run build
npm run lint
```
