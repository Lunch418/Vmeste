# CHANGELOG.md — «Вместе»

## [Unreleased]

### Исправлено
- **Критический баг эскроу-депозитов**: подтверждение встречи одним участником
  (`confirm/selfie`, `confirm/qr/scan`) больше не разблокирует депозиты всех
  остальных участников события — теперь каждое участие рассчитывается
  независимо (`backend/app/routers/confirm.py`).
- Добавлена обработка no-show: если участник не подтвердил встречу до
  автоархивации события (2 часа после времени встречи), его депозит уходит
  постеру (`backend/app/archive.py`).
- Добавлено окно подтверждения (`meeting_confirm_window_minutes`) — раньше
  настройка существовала, но не применялась.
- WebSocket-чат теперь проверяет забаненность пользователя при подключении
  (раньше проверялась только валидность токена).
- SMS-заглушка (`app/sms.py`) теперь видна в логе сервера — код подтверждения
  не выводился из-за уровня логирования по умолчанию.

### Добавлено
- Backend MVP на FastAPI: авторизация по телефону, события, депозиты
  (эскроу-заглушка ЮKassa), чат (REST + WebSocket), подтверждение встречи
  (AR-селфи метаданные + QR), рейтинги, уведомления, автоархивирование.
- Frontend MVP на React + TypeScript + Vite (PWA): полный набор экранов по
  `specs/NAVIGATION.md`, тёмная тема по `specs/COMPONENTS.md`.
- 70 backend-тестов (pytest) и 11 frontend-тестов (Vitest).
- `docker-compose.yml` (backend + Postgres + Redis).

### Известные ограничения
См. `specs/CHANGES.md` (заглушки: SMS-провайдер, ЮKassa, распознавание лиц)
и `specs/TEST_REPORT.md` (9 более мелких найденных, но не исправленных
проблем — например, возрастной/гендерный фильтр событий не применяется при
