# Проект: «Вместе»

Платформа для поиска компании на совместные активности.
Старое рабочее название — «Пошли». НЕ использовать.

## Стек
- Frontend: React + TypeScript, PWA
- Backend: Python + FastAPI
- БД: PostgreSQL, Redis

## Правила
- Формат обмена между агентами: Markdown в specs/
- Диаграммы: Mermaid
- Язык кода: английский
- Язык документации: русский
